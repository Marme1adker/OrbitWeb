# Orbit — страницы для GitHub Pages

Готовая статическая структура, без npm, сервера, внешних шрифтов и сборщика. Это отдельный сайт документов; исходники приложения и секреты сюда не входят.

## Перед публикацией

Тексты — проект условий и политики под Orbit 0.14.3, сверенный с текущим кодом, а не гарантия юридического соответствия или одобрения Discord. Проверь их от своего имени; если функции/обработка изменятся, обнови документы.

В index.html, terms.html и privacy.html замени:
- [[DEVELOPER_NAME]] — действительное имя разработчика/оператора или его подходящее официальное наименование.
- [[CONTACT_EMAIL]] — действующий email для поддержки и запросов об удалении данных.
- [[PUBLICATION_DATE]] — дату, с которой документы действуют.

После заполнения удали в каждом HTML блок от <!-- DRAFT-BEGIN --> до <!-- DRAFT-END --> включительно. До этого страницы явно помечены как черновики. Не вставляй пароль почты, Discord Client Secret, токены, api_hash или личный номер телефона. Имя и контакт станут публичными.

Необязательно: если PowerShell разрешает локальные скрипты, prepare.ps1 заполняет эти поля и удаляет предупреждение после подтверждения. Альтернатива без скриптов — редактирование файлов в GitHub. Не меняй политику запуска Windows ради этого скрипта.

## Публикация

1. Создай публичный репозиторий, например orbit-legal. Репозиторий сайта не требует публикации исходников Orbit.
2. Загрузи СОДЕРЖИМОЕ этой папки в корень репозитория (не ZIP и не папку целиком). Для сайта нужны index.html, terms.html, privacy.html, style.css, orbit.svg и .nojekyll. README можно оставить; prepare.ps1 публиковать не требуется.
3. В репозитории: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save.
4. Дождись публикации и возьми адрес в Settings → Pages. Например: https://YOUR-USERNAME.github.io/orbit-legal/
5. Проверь terms.html и privacy.html в приватном окне без входа в GitHub/Discord. Ссылки должны открывать документы, а не исходный код или приглашение на сервер.

## Discord Developer Portal

В General Information соответствующего приложения укажи:
- Terms of Service URL: https://YOUR-USERNAME.github.io/orbit-legal/terms.html
- Privacy Policy URL: https://YOUR-USERNAME.github.io/orbit-legal/privacy.html

Замени YOUR-USERNAME и orbit-legal фактическими значениями. Не вставляй github.com/.../blob/... вместо адреса GitHub Pages.

Сохрани изменения. Эти ссылки не предоставляют Discord RPC/voice-разрешения и не гарантируют одобрение приложения. Текущая версия Orbit управляет своим голосом через сочетания клавиш, а не OAuth/RPC.

После публикации нужно также добавить реальные ссылки в «О программе» Orbit, чтобы документы были доступны из приложения. Адреса пока неизвестны; в текущей сборке они не добавлены. Пришли адрес опубликованного сайта для следующего обновления приложения.
